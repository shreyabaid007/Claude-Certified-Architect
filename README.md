# Claude Certified Architect — Study Notes

Study notes for the **Claude Certified Architect** exams, Foundations and Professional. Scannable and revision-friendly: mermaid diagrams, comparison tables, exam traps, and a quick-revision summary at the bottom of every note.

> [!IMPORTANT]
> **Verify as you read.** The platform moves fast. Check specific claims against [Anthropic's documentation](https://docs.claude.com) — if a note contradicts the docs, the docs win.

## Exam Overview

| | Foundations | Professional |
|---|---|---|
| **Exam code** | CCAR-F | CCAR-P |
| **Focus** | API skills, prompt engineering, tool use, RAG, MCP, Claude Code | Solution architecture, enterprise integration, safety and risk, stakeholder engagement, team enablement |
| **Modules** | 4 | 5 |
| **Notes here** | 11 | 29 |
| **Official course** | [Foundations](https://anthropic-partners.skilljar.com/claude-certified-architect-foundations-certification) | [Professional](https://anthropic-partners.skilljar.com/claude-certified-architect-professional-certification) |

Certification is open to organisations in the **Claude Partner Network**. Prep courses and exam guides live in the [Anthropic Partner Academy](https://anthropic-partners.skilljar.com/page/partner-certifications). Scheduling runs through [Pearson VUE](https://www.pearsonvue.com/us/en/anthropic.html), at a test centre or online with OnVUE proctoring; register through the Partner Academy first, then receive Pearson credentials by email. Retakes are gated at **14 days** after a first attempt, **30 days** after a second, **90 days** after a third, with up to **4 attempts per exam in any rolling 12-month period**. Badges are issued through [Credly](https://www.credly.com).

**Fees as of July 2026: $125 (Foundations), $175 (Professional).** Check the current course pages before booking.

> [!NOTE]
> Exam format, domain weightings, and fees are set by Anthropic and change between exam versions. Read them from the current official exam guide, not from any third-party summary, including this one.
